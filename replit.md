# Running Zumrad on Replit

- Dependencies are installed with Bun using the existing package manifest.
- Press Run to start the `Start application` workflow.
- Run command: `bun run dev --host 0.0.0.0 --port 5000`.
- Open Preview to use the application.
- Keep the existing server-side credentials in Replit Secrets; never put them in source code.

The login page was verified in Preview. Signed-in features and external-service operations were not verified during startup setup.
